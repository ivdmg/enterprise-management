# Smart Enterprise Hub — Backend & Data Engineering

Легковесный бэкенд платформы Smart Enterprise Hub поверх Google Диска и автоматического контроля рисков для строительно-тендерных компаний (44-ФЗ / 223-ФЗ).

---

## 📊 1. Генерация эталонных Excel-шаблонов и Мок-Диска в 1 клик

Для генерации 5 утвержденных бизнесом стандартизированных Excel-шаблонов (`.xlsx`) со строгой валидацией (`DataValidation`), стилизацией шапок (`#1E293B`) и наполнением реалистичными данными (20+ строк в каждой таблице + 4 бизнес-триггера алертов) используется консольный скрипт:

### Генерация Mock Google Drive с данными (Фаза 2):
```bash
python backend/scripts/generate_standard_templates.py --with-mock-data
```

### Генерация только чистых пустых эталонных шаблонов (Фаза 1):
```bash
python backend/scripts/generate_standard_templates.py
```

### Проверка и валидация шаблонов и структуры диска:
```bash
python backend/scripts/generate_standard_templates.py --verify
```

## 🚨 3. Реализованные бизнес-триггеры для системы алертов

1. **Контракт со сроком через 3 дня и незакрытыми КС на 2 500 000 ₽**:
   - Номер: `0173200001426000045` (Клиническая больница №1 им. Пирогова).
   - Сумма: 24 500 000 ₽, закрыто КС: 22 000 000 ₽. Срок окончания работ: через 3 дня.
2. **Банковская гарантия, истекающая через 5 дней**:
   - Номер: `0348300054226000088` (Теплосети мкр. "Южный").
   - Срок действия банковской гарантии: через 5 дней.
3. **Критический алерт юристу (дедлайн 48 часов)**:
   - Задача: *"Подать протокол разногласий к проекту госконтракта №014820000212600015"*.
   - Роль: `Юрист`, Приоритет: `КРИТИЧЕСКИЙ_ШТРАФ`, Штраф: 1 250 000 ₽.
4. **Прогнозируемый кассовый разрыв через 9 дней**:
   - Крупное плановое списание 4 200 000 ₽ за поставку силового трансформатора по счету №1042/ЭП, уводящее баланс кассы в дефицит (-2 920 000 ₽).
