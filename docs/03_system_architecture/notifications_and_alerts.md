# Система умных уведомлений, мониторинга дедлайнов и предотвращения штрафов

Главная функция платформы с точки зрения собственника и генерального директора — это **упреждающее выявление точек риска** («Где мы теряем деньги или рискуем получить штраф?»).

---

## 1. Типология бизнес-рисков и триггеров алертов

Система анализирует данные из всех загруженных Excel-документов и автоматически формирует события 4 уровней критичности:

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 🔴 КРИТИЧЕСКИЙ (CRITICAL / FIRE)                                        │
│ - Просрочка сдачи этапа по контракту (начисление пени/неустойки)        │
│ - Кассовый разрыв (дефицит средств на выплату зарплаты или налогов)    │
│ - Истечение срока банковской гарантии (< 3 дней)                        │
├─────────────────────────────────────────────────────────────────────────┤
│ 🟡 ПРЕДУПРЕЖДЕНИЕ (WARNING)                                             │
│ - До дедлайна сдачи КС-2/КС-3 осталось менее 5 рабочих дней             │
│ - Рост дебиторской задолженности контрагента сверх лимита              │
│ - Недовыполнение производственного плана более чем на 15%              │
├─────────────────────────────────────────────────────────────────────────┤
│ 🔵 ИНФОРМАЦИОННЫЙ (INFO / MILESTONE)                                    │
│ - Успешное закрытие этапа договора / поступление оплаты                │
│ - Загрузка и распознавание нового реестра менеджером                   │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. Логика расчета финансовых последствий (Financial Impact Engine)

В отличие от стандартных задачников (Trello, Битрикс24), уведомление содержит **точный расчет финансового ущерба**:

1. **Неустойка по госконтрактам (44-ФЗ / 223-ФЗ)**:
   $$\text{Штраф} = \text{Сумма невыполненных обязательств} \times \frac{1}{300} \text{ Ключевой ставки ЦБ РФ} \times \text{Дней просрочки}$$
   *Пример текста алерта*:
   > «⚠️ **Объект №101 (Кислородный цех)**: отставание 4 дня. Текущая расчетная неустойка: **48 200 ₽**. При задержке до конца недели штраф составит **112 000 ₽**.»

2. **Кассовый разрыв по ФОТ и налогам**:
   Система сравнивает текущий подтвержденный остаток денежных средств на счетах с плановыми обязательствами по заработной плате и налогам до конца месяца.
   *Пример текста алерта*:
   > «🚨 **Кассовый риск через 6 дней**: Обязательства по ФОТ: **402 818 ₽**, фактический остаток: **335 079 ₽**. Прогнозируемый дефицит: **67 739 ₽**.»

## 3. Каналы доставки уведомлений

### 3.1. Интерактивный Центр Уведомлений в Личном кабинете (In-App)
- Верхняя панель со счетчиком «горящих» событий с цветовой пульсацией.
- Модальное окно / шторка со списком задач, сгруппированных по степени срочности.
- Кнопка быстрого действия: *«Назначить ответственного»*, *«Сформировать акт»*, *«Отметить закрытым»*.

### 3.2. Telegram-бот руководителя (Zero-Cost Instant Alerts)
- **Стоимость**: 0 рублей (официальный Telegram Bot API).
- **Сценарии**:
  - **Утренний дайджест (08:30)**: Сводка на день — остаток на счетах, 3 главных дедлайна, горящие объекты.
  - **Мгновенный пуш при критическом событии**: если менеджер загрузил отчет, где обнаружена просрочка или штраф.
  - **Интерактивные кнопки (Inline Keyboards)**: прямо из Telegram директор может нажать *«Запросить объяснение у прораба»* или *«Продлить срок»*.

### 3.3. Email-отчеты (Daily / Weekly Digest)
- Формирование аккуратного HTML-письма с инфографикой за прошедшую неделю для совета директоров и учредителей.

```
 [Загруженные таблицы] ──> [Унифицированная БД]
                                 │
                                 ▼
                     [Фоновый Scheduler (Cron)]
                     - Проверка дедлайнов каждые N минут
                     - Пересчет кассового баланса
                                 │
                                 ▼
                   [Rules & Risk Evaluation Engine]
                                 │
                 ┌───────────────┼───────────────┐
                 ▼               ▼               ▼
          [In-App Alerts] [Telegram Bot]  [Email Service]
```
