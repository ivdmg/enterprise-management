# База знаний и документация проекта «Smart Enterprise Hub»

Добро пожаловать в репозиторий проектной и технической документации для создания платформы **Smart Enterprise Hub** — центра операционного управления предприятием на основе умного парсинга разнородных Excel-документов и автоматического контроля рисков.

---

## 📂 Структура репозитория

В корне проекта выделены три функциональные зоны:
- **`agents/`** — Системные ограничения, безопасность и правила дизайна (General Rules, Security Constraints, UI Design Constraints).
- **`docs/`** — Полная техническая база знаний, продуктовое видение, архитектура БД и API-контракты.
- **`tasks/`** — Задачи для агентов разработчиков и руководство для Техлида (`TECH_LEAD_GUIDE.md`).

## 🚀 Краткое резюме ключевых архитектурных решений

1. **Продуктовая ценность**: Руководитель МСБ избавляется от необходимости открывать десятки Excel-файлов. Система формирует экран «Где горит?» за секунды, предупреждая о штрафах (44-ФЗ / 223-ФЗ) и кассовых разрывах.
2. **Технологический стек**:
   - **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons (стильный темный дашборд, быстрая загрузка).
   - **Backend**: Python 3.11+ / FastAPI (асинхронный монолит, нативные Rust-библиотеки парсинга `python-calamine`, `openpyxl`, легкие SDK LLM).
   - **База данных**: PostgreSQL 16 Alpine (в Docker с оптимизированным профилем памяти $\approx 120$ МБ RAM, строгая мультиарендность по `company_id`, JSONB для кастомных свойств).
   - **Файловое хранилище**: Локальный том Docker с абстракцией `IStorageService` (готовность переключения на Яндекс/Selectel S3 в 1 строчку конфига, 0 ₽ затрат в MVP).
   - **Фоновые задачи и кэш**: Встроенный `BackgroundTasks` + `APScheduler` + in-memory LRU. Отказ от тяжелых Redis и Celery для экономии памяти и надежности.
3. **Бюджетность и TCO**: Все сервисы потребляют менее **450 МБ RAM** в пике и запускаются на VPS в РФ всего за **180–250 ₽/месяц** на 10 компаний-клиентов.
