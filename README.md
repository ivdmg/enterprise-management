## 🌟 О продукте

**Smart Enterprise Hub** — специализированная цифровая ERP/Dashboard-платформа для строительных, подрядных и проектных организаций, работающих по **44-ФЗ и 223-ФЗ**.

Платформа решает главную проблему строительного бизнеса — **разрозненность данных** (бухгалтерия в 1С, снабжение в Excel, сметы на сетевых дисках, задачи в мессенджерах) и обеспечивает сквозной контроль:
- 🚨 **Главный экран «Где горит?»**: сводка критических рисков дня, автоматический расчет штрафов и пеней за просрочку обязательств по 44-ФЗ (1/300 ставки ЦБ РФ) и мониторинг дедлайнов банковских гарантий (риск попадания в РНП).
- 🏗️ **Тендеры и объекты**: сквозной визуальный степпер стадий контракта с защитой от случайного переключения («Защита от дурака»).
- 📦 **Снабжение и закупки**: реестр номенклатуры ТМЦ, счетов и поставок с переходом статусов («Счет на оплате» $\rightarrow$ «Оплачено» $\rightarrow$ «В пути» $\rightarrow$ «На объекте»).
- 🚜 **Диспетчерская**: оперативный статус парка спецтехники («На объекте», «В ремонте», «Простой»).
- 📋 **Смарт-реестр задач**: матрица поручений с привязкой к 9 ролям и объектам СМР.
- 📂 **Автоматический файловый хаб**: прямая интеграция с Google Диском — документы, сброшенные в папки, сами парсятся и обновляют таблицы.

## ☁️ Инструкция по настройке Google Диска

### 1. Нужно ли создавать диск и как связать с системой?

**Да, вам потребуется обычный аккаунт Google (личный Google Drive или корпоративный Google Workspace).**
Вам **НЕ** нужно вручную вбивать строки в базу — система берет файлы из облака.

#### Пошаговое подключение сервисного аккаунта:
1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект, например `Enterprise-Hub-Sync`.
3. В разделе **APIs & Services $\rightarrow$ Library** найдите и включите **Google Drive API**.
4. В разделе **APIs & Services $\rightarrow$ Credentials** нажмите **Create Credentials $\rightarrow$ Service Account**:
   - Назовите аккаунт, например `hub-storage-sync`.
   - Нажмите на созданный сервисный аккаунт, перейдите во вкладку **Keys $\rightarrow$ Add Key $\rightarrow$ Create new key $\rightarrow$ JSON**.
   - Сохранится JSON-файл ключа (например, `service_account.json`).
5. Скопируйте этот файл в папку бэкенда:
   ```
    backend/credentials.json
   ```
   *(либо укажите путь к нему в `backend/.env` в параметре `GOOGLE_DRIVE_CREDENTIALS_PATH`).*
6. Скопируйте email сервисного аккаунта (он выглядит как `hub-storage-sync@enterprise-hub-sync.iam.gserviceaccount.com`).
7. На вашем Google Диске создайте одну корневую папку, например **`SmartEnterprise_Hub`**.
8. Нажмите правой кнопкой мыши по этой папке $\rightarrow$ **Поделиться (Share)** $\rightarrow$ добавьте скопированный email сервисного аккаунта с правами **«Редактор» (Editor)**.
9. Откройте папку в браузере и скопируйте её ID из адресной строки:
   `https://drive.google.com/drive/folders/`**`1AbCdEfGhIjKlMnOpQrStUvWxYz`**
10. Пропишите этот ID в `backend/.env`:
    ```env
    GOOGLE_DRIVE_ROOT_FOLDER_ID="1AbCdEfGhIjKlMnOpQrStUvWxYz"
    ```

### 2. Структура папок и поддерживаемые форматы

При первом старте системы бэкенд **автоматически создаст** внутри вашей папки следующие подкаталоги:

| Папка на Google Диске | Назначение | Поддерживаемые форматы | Что происходит после загрузки |
| :--- | :--- | :--- | :--- |
| `📁 01_Сметы_и_Тендеры` | Локальные сметы, ведомости объемов, акты КС-2/КС-3 | `.xlsx`, `.xls` | Создаются или обновляются объекты СМР, плановые бюджеты и этапы |
| `📁 02_Счета_Снабжения` | Счета на оплату материалов и оборудования | `.xlsx`, `.pdf` | Создаются строки в реестре «Снабжение» со статусом «Счет на оплате» |
| `📁 03_Банк_и_Касса` | Выписки из клиент-банка (Сбер, ВТБ, Альфа), кассовые ордера | `.txt` (1CClientBankExchange), `.xlsx` | Платежи разносятся по счетам ТМЦ («Оплачено»), обновляется график кэшфлоу |
| `📁 04_Путевые_листы` | Журналы учета техники, путевые листы водителей | `.xlsx` | Обновляются статусы машин в «Диспетчерской» («На объекте» / «Простой») |
| `📁 05_Обработано` | Архив успешно прочитанных документов | Все | Файлы автоматически перемещаются сюда роботом, чтобы не двоиться |
| `📁 99_Ошибки_парсинга` | Файлы с поврежденной структурой или неверными колонками | Любые | Документ перемещается сюда, в свойства файла пишется текст ошибки |

---

### 3. Как загружать документы

1. **С компьютера**: просто перетащите Excel-файл сметы или счет в соответствующую папку Google Диска.
2. **Со смартфона / планшета**: установите приложение Google Drive, откройте нужную папку и нажмите кнопку `+` (Загрузить фото/скан/файл).
3. **Автоматический опрос**: бэкенд каждые 120 секунд опрашивает папки. Как только файл обнаружен:
   - Он скачивается и валидируется.
   - Данные попадают в базу данных и отображаются в веб-интерфейсе.
   - Исходный файл остаётся на месте. После редактирования повторная синхронизация обновит его данные.
4. **Ручная синхронизация**: если нужно обновить данные немедленно, в веб-интерфейсе в Header нажмите кнопку **«Синхронизировать Google Диск»** (или через Бургер-меню на мобильном телефоне).

## 🚀 Быстрый запуск системы

### Шаг 1: Запуск бэкенда (FastAPI)

1. Откройте терминал в папке проекта:
   ```bash
   cd "backend"
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   # Активация на Windows:
   venv\Scripts\activate
   # Установка пакетов:
   pip install -r requirements.txt
   ```
3. Проверьте файл `.env` (создайте копию из `.env.example` при необходимости).

### Шаг 2: Мгновенное наполнение базы демо-данными

Чтобы сразу увидеть полностью заполненную живую систему со стройками, техникой, счетами и рисками:
```bash
python -m app.db.seed
```
*Скрипт создаст 5 объектов СМР, банковские гарантии, 15 позиций снабжения, парк спецтехники и задачи кураторов.*

4. Запустите сервер:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
   API доступен по адресу: `http://localhost:8000/docs` (Swagger UI).

---

### Шаг 3: Запуск фронтенда (React / Vite)

1. Откройте второй терминал:
   ```bash
   cd "frontend"
   ```
2. Установите зависимости и запустите dev-сервер:
   ```bash
   npm install
   npm run dev -- --host
   ```
3. Веб-интерфейс откроется по адресу: `http://localhost:5173`.

---

### Шаг 4: Доступ со смартфона (iPhone / Pixel) по Wi-Fi

Фронтенд и бэкенд запущены с параметром `--host 0.0.0.0`. Это означает, что вы можете открыть интерфейс с любого мобильного телефона в той же сети Wi-Fi:
1. Узнайте локальный IP-адрес вашего компьютера (в Windows cmd: `ipconfig`, строка `IPv4-адрес`, например `192.168.1.45`).
2. В браузере Safari или Chrome на смартфоне перейдите по адресу:
   ```
   http://192.168.1.45:5173
   ```
3. Вы получите оптимизированный мобильный вид с нижним баром навигации и Бургер-меню.

## 👥 Сценарии использования по ролям

### 1. Генеральный директор / Собственник
- **Экран «Где горит?»**:
  - Утренний мониторинг 3-х карточек:
    - 🔴 **Критические риски**: дедлайны по контрактам $\le 3$ дней, незакрытые обязательства.
    - 🟡 **Предупреждения**: счета на оплате с приближающимся сроком отгрузки.
    - 🟠 **Штрафы и неустойки 44-ФЗ**: расчетная сумма финансовых санкций при срыве графика.
  - Клик по любой карточке открывает детальный список с виновными объектами и ответственными кураторами.
- **Вкладка «Финансы»**:
  - Соотношение входящего кэшфлоу (оплаты от заказчиков) и исходящих расходов (субподряд, материалы, зарплата, лизинг техники).

### 2. Руководитель проектов (ГИП / РП)
- **Вкладка «Тендеры и объекты»**:
  - Контроль стадий линейного степпера контракта (`ТЗ` $\rightarrow$ `Тендер` $\rightarrow$ `БГ` $\rightarrow$ `Контракт` $\rightarrow$ `СМР` $\rightarrow$ `Сдача КС-2`).
  - При попытке сдвинуть стадию открывается **ConfirmModal («Защита от дурака»)** — случайный клик не изменит статус этапа.
  - Индикатор **«Банковская гарантия»**: зеленый бейдж означает безопасность; красный бейдж «Риск РНП (< 5 дней)» сигнализирует о необходимости срочно продлить обеспечение контракта.
- **Вкладка «Смарт-реестр задач»**:
  - Постановка оперативных задач прорабам и снабженцам с указанием штрафных рисков при просрочке.

### 3. Специалист отдела снабжения
- **Вкладка «Снабжение и закупки»**:
  - Работа со списком счетов ТМЦ.
  - Быстрое изменение статуса с подтверждением:
    `Счет на оплате` $\rightarrow$ `Оплачено` $\rightarrow$ `В пути` $\rightarrow$ `На объекте`.
  - Мобильный режим: на стройплощадке прораб открывает со смартфона карточку-аккордеон поставки бетона или арматуры, сверяет объем и в один клик переводит статус в «На объекте».

### 4. Диспетчер / Главный механик
- **Вкладка «Диспетчерская»**:
  - Мониторинг готовности парка машин (самосвалы, экскаваторы, краны).
  - Единые аккуратные плашки статусов:
    - 🟢 `На объекте` (задействована в СМР)
    - 🔴 `В ремонте` (заказ запчастей)
    - 🟡 `Простой` (резерв / отсутствие машиниста).

### 5. Главный бухгалтер / Финансист
- **Вкладка «Файлы и интеграция»**:
  - Загрузка файла выписки клиент-банка (`1CClientBankExchange.txt`).
  - Система сама находит платежи поставщикам и переводит счета в снабжении в статус «Оплачено».
