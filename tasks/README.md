Цель первого показа 23 ноября 2026 года — открыть главную страницу по HTTPS без входа и за несколько минут показать сквозной сценарий на вымышленных данных: руководитель видит сигнал, открывает запись реестра, смотрит срок и связанный этап или задачу. ### Локальный запуск фазы 2

Из корня демо-worktree, Python 3.12 и Node.js 24:

```sh
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r backend/showcase/requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build:showcase
cd backend
../.venv/bin/python -m uvicorn showcase.main:app --host 127.0.0.1 --port 8011
```

Открыть `http://127.0.0.1:8011/`. После правок фронтенда повторить `npm --prefix frontend run build:showcase` из корня. `/health` возвращает `source: synthetic`. Для локального прогона нужны только исходники и зависимости. `DEMO.md`, `LAPTOP_SETUP.md`, `render.yaml`, обычный `Dockerfile` и команда `npm run dev` описывают другие режимы проекта.

Для сборки под отдельный сервис использовать `docker build -f Dockerfile.showcase -t enterprise-hub-showcase .`. Корень демо-папки Google Drive уже создан владельцем. Подключение, создание структуры внутри папки и заполнение синтетическими таблицами входят в фазу 3.

**Проверка фазы 1.** Собраны обычный и демо-фронтенд. FastAPI запущен с очищенным окружением. В чистом профиле Chromium открыты обзор и шесть разделов, проверены ответы демо-API и отсутствие внешних запросов при загрузке. Изменяющие запросы возвращают 405, клиентские и платформенные маршруты — 404. Docker-образ ещё предстоит собрать и проверить при подготовке отдельного сервиса.
